Token Radar ranks 200 pre-token DeFi protocols by fitted implied token value (TVL × category FDV/TVL multiple × growth × size × launch odds), with an 8-step costed airdrop farm plan per protocol, in a sortable offline dashboard. The value model is fitted from 128 tokened comparables and validated by held-out tests (median log10 error 0.47, token-status AUC 0.72). It reads the DefiLlama snapshot at /input/snapshot.json and writes the board, dashboard and dossier to /output.

## Run it

```sh
node main.ts
```
